# E-zine digital: Raça Negra

Trabalho escolar sobre a banda Raça Negra: nascimento, álbuns, integrantes e músicas mais ouvidas.

## Como publicar no GitHub Pages
1. Crie um repositório público (ex.: `ezine-raca-negra`).
2. Envie TODOS os arquivos e a pasta `fotos` deste projeto (Add file > Upload files).
3. Settings > Pages > Branch: `main` / pasta `/ (root)` > Save.
4. Aguarde 1-2 minutos. O link será `https://SEU-USUARIO.github.io/ezine-raca-negra/`.

## Fotos
Veja `fotos/LEIA-ME.txt` para os nomes dos arquivos.
